Protocol, numerical conventions, and verification

All candidates ran on the unchanged real Simulator and YardState. Runtime is the simulation loop wall time, excluding input loading and strategy initialization. No internal fast simulator was used. The full and strict-prefix θ₀ traces match the frozen control exactly. The score uses sum(p_tot) plus weighted deviations to preserve the control’s floating-point summation order; mathematically this is θᵀΦ with θ₁ fixed at one.

Optimization: seed 42; 120 objective evaluations; one deterministic sweep of both signs over coordinates 2–16 at step 0.25, then 0.08; remaining calls use (1+6)-ES, with a final partial batch to respect the cap. Bounds [-2,3]. J = early reshuffles + 5||θ₂:₁₆−θ₀₂:₁₆||². Accept only strict decreases. σ starts at .06 and decays by .85 on stalls. No Days 13–20 metrics enter selection.

Track 2: CD2’s compaction term applies to low-urgency arrivals, defined consistently as missed_load or u<.15. CD1 changes height tie-breaking only for those arrivals. CD3 uses exactly B09/B10; B08 is also 720 slots in the supplied layout, but the named sink blocks were preserved.

Pair sampling: seed 707, uniform eligible arrival followed by uniform current real resident, with replacement. 150,000 fit pairs from Days 1–8 and 80,000 validation pairs from Days 13–16. Labels use actual successful exits, strict chronological outcome boundaries, and complete 96-hour horizons. Missing exit within a horizon means survival through the horizon; no censored row is assigned an outcome beyond its split. Initial residents remain in validation. See dataset_manifest.json for precise feature conventions.

M0 calibration has exactly one fitted parameter: slope of frozen logit, no intercept. M1 has an unpenalized intercept and L2=10 in summed loss; fit-only numeric standardization. M2 uses 30 depth-3 histogram Newton boosting trees, learning rate .1, min leaf 200, 16 fit-only quantile bins. Model hyperparameters were fixed before validation. A feature implementation correction changed port_weight_diff from weight-only rank to the prescribed combined frozen port/weight order; all final screen results use the corrected feature with unchanged hyperparameters. Repeated pairs and shared states are dependent, so these point estimates are diagnostics rather than independent-sample confidence claims.

Initial implementation diagnostics caught and corrected a stale overdue-descriptor cache before optimization. The accepted θ₀ and prefix hashes are exact. Scalar/vector agreement and synthetic sparse-stack tests cover full sparse stacks, physical gaps, ghost stacks, failed target removal, metadata restoration, and cached/live multistep equivalence.
